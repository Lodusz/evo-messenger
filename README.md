
# evo-messenger




Микросервисный мессенджер 

Стек технологий
Backend:Go (Golang), Gin
Real-time: WebSockets
Message Broker: Apache Kafka, Zookeeper
Database: PostgreSQL
Infrastructure: Docker, Docker Compose

Быстрый старт
Требования
Docker и Docker Compose
Go (версия 1.22+) — опционально, для локальной разработки и тестов

Запуск инфраструктуры и сервисов
Команда поднимет PostgreSQL, ZooKeeper, Kafka, auth-service и chat-service:

docker compose up -d --build
